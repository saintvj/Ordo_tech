## Current MVP
- **Linear Pass-and-Play Setup**: Guides the host through creating a gathering and menu selection.
- **Manual Menu Editor**: Allows the host to edit the menu categories and items before starting the ordering process.
- **Participant Wizard**: Sequentially prompts each participant to add their name and select items from the menu.
- **Order Editing**: Participants can easily edit item quantities. Changes are applied locally until confirmed.
- **Review Orders**: A comprehensive final checkpoint before Waiter Mode. Hosts can edit any participant's order directly from this screen.
- **Waiter Mode**: Food-centric view tracking total dish counts and checkboxes for each participant receiving the dish.
- **Session Summary**: Final list displaying every participant and their selected items.

## Future Modules
- **Menu Scan**: OCR + AI to digitize physical menus.
- **Billing & Payments**: Calculation of totals, split rules, and payment gateway integration.
- **Multi-device Sync**: Collaborative ordering across multiple devices without internet.
- **QR Sharing**: Joining sessions via QR code.
- **Restaurant Integration**: Pushing finalized orders directly to a restaurant's POS.
- **Notifications**: Real-time alerts.
