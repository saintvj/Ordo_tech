# Contributing

## Coding Standards for AI-Generated Code
1. **Clean Code**: Code must follow the architecture outlined in `ARCHITECTURE.md`.
2. **No Placeholders**: Do not introduce empty files that break the analyzer. Ensure all files contain meaningful code or are omitted until needed.
3. **No TODOs in Code**: Complete implementations or track them in `TODO.md` instead of leaving `// TODO:` comments in code.
4. **Formatting**: Always format dart files. Ensure trailing commas are used for better readability.
5. **Material 3**: Ensure all UI elements use Material 3. Do not hardcode colors; use the app's `ThemeData`.
