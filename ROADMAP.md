# Ordo Roadmap

## Version 0.1
**Offline Dining Session (MVP)**
- Core pass-and-play wizard flow.
- Participants enter names and order sequentially.
- Mock menu ordering.
- Waiter mode (grouped by food item).
- Session summary.

## Version 0.3.1
**Real Session Menu Foundation**
- Data models refactored for a real menu.
- Manual menu editor screen added.

## Version 0.3.1.5
**Order Review & Edit Before Waiter Mode**
- Participant order editing with local state changes.
- Final review checkpoint with participant subtotal and grouped items.
- Seamless editing of orders from the review screen.
## Version 0.2
**Menu Scan (OCR)**
- Integration of OCR and AI.
- Ability to take a picture of a physical menu and digitize it to replace the mock menu.

## Version 0.3
**Billing**
- Price tracking for menu items.
- Split bill calculations (even, exact, percentage).
- Tax and tip additions.

## Version 0.4
**Multi-device**
- Offline peer-to-peer sync (Bluetooth / Local WiFi).
- Multiple users ordering simultaneously from their own devices.
